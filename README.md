# imgWEBP
Convert .jpg .jpeg or .png files into .webp files

## Usage
Download a binary file for your os from the releases page. 
Under macos or linux, you can do this:
```./imgwebp```

Under Windows just do this in cmd:
```imgwebp.exe```

Possible flags to run:
```--input=[DIRECTORY/]```
```--output=[DIRECTORY/]```
```--delete```
```--quality=[INTEGER]```

Example command (macos/linux):
```./imgwebp --input=myPhotos/ --output=webPhotos/ --quality=67 --delete```
